# The Reading Room

A book recommendation website made for the Group 10 Web Technology project.

## Run the project

Open `index.html` in a browser, or serve the folder with a local web server. An internet connection is needed for the Tailwind CDN and book covers from Open Library. If a cover is unavailable, the title and author are shown instead.

## Features

- Browse a curated collection and search by title or author.
- Filter books by genre, view details and give a personal rating.
- Add or remove books from the Want to Read list. Ratings and the list are saved in the browser using localStorage.
- Contact form with validation and a demo confirmation. It does not send or store messages; a backend would be needed for that.

The site uses HTML, Tailwind CSS, a small custom stylesheet and vanilla JavaScript. The book catalogue is in `script.js`.
